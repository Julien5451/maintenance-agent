## 运行中容器的独立网络失败

额外在已运行 API 容器内执行只读工具探针，不创建任务、不写数据库：[容器探针](container_model_probe.json) 失败，异常类 `OpenAIConnectionError`，约 45.314 秒。

[网络分层检查](container_network_diagnosis.json) 显示：

- 服务地址不是回环地址，DNS 解析成功。
- IPv4 TCP 连接超时；IPv6 返回 `errno=101`（网络不可达）。请求尚未到达可验证认证或工具参数的阶段。
- 容器没有代理环境；WSL 主机有代理且该服务不在 NO_PROXY 中。由此推断，主机与容器的出口路径差异是首要排查方向，不能仅凭该现象断言具体防火墙规则。

因此：**密钥已正确复用，后端已加载配置，但当前容器仍不能连接模型服务，不能声称 Docker 中的真实模型闭环已通过。** 原有 10 项容器 mock 检查仍是独立证据，不能替代这项真实网络验证。需要另行解决容器出网/代理配置。

## 调试中保留的失败事实

第一次 Docker 构建在解析 `python:3.12-slim` 时因 Docker Hub 超时失败。随后改用 uv 官方 GHCR Python 3.12 派生镜像；直连依赖下载极慢，停止后使用可选构建网络覆盖与已核实无认证信息的本机代理，约 57 秒装好依赖。传代理的操作首次被自动审批拒绝，补充只读布尔检查证明无用户名、密码或查询参数后，重新审批通过；没有将代理值写入项目。

随后镜像导出期间构建进程异常退出，日志显示对应 WSL 会话发生退出和重新启动；未发现内存不足证据。保持普通用户 WSL 会话后，利用缓存重试完成导出。上述环境失败均保留在此记录，没有计为真实模型或业务用例通过。

第一次 UI AppTest 的 3 条用例在本地 HTTP 健康检查处返回 502，未进入界面交互，原因是 WSL 代理环境影响 localhost 请求。UI 现对本地 API 使用 `trust_env=False`；最终测试在保留代理环境且不设置 NO_PROXY 替代行为的条件下通过。

早期缺配置的 blocked 时间戳报告仍保留。本轮真实调用后出现 6 条业务失败，原始时间戳报告同样保留，没有修改冻结用例、放宽校验或重跑挑选结果。真实评测脚本每次保存独立时间戳报告。
